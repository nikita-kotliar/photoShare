# PhotoShare

**Соціальна мережа для обміну світлинами.** Публікуйте фото з описом і тегами, змінюйте їх через Cloudinary, діліться трансформованою версією через QR-код, коментуйте й оцінюйте роботи інших. Три ролі доступу: користувач, модератор, адміністратор.

**[Відкрити сайт](https://kotdenik.cx.ua/photoshare/)** · **[Документація API (Swagger)](https://kotdenik.cx.ua/photoshare-api/docs/)**

Навчальний командний проєкт: технічне завдання курсу і дизайн у Figma.

## Можливості

**Світлини**
- Стрічка з пагінацією, пошук за описом і тегом, фільтри за датою, рейтингом, кольором і автором, сортування за датою або рейтингом.
- Публікація з описом і до 5 тегів; поворот, квадратна обрізка, чорно-білий, сепія і розмиття через Cloudinary.
- QR-код на трансформовану версію світлини; оригінал зберігається, а слайдер «до / після» показує різницю.
- Палітра головних кольорів кожної світлини, клік по кольору шукає схожі.
- Світлина тижня: найкраще оцінена за останні 7 днів.

**Спільнота**
- Коментарі (автор може редагувати свій) і рейтинг від 1 до 5 зірок, одна оцінка на людину.
- Публічні профілі з галереєю, датою реєстрації і досягненнями.
- Сповіщення про коментарі й оцінки ваших світлин.

**AI на базі Claude**
- Пропозиція опису і тегів під час завантаження світлини.
- Помічник модератора: нові коментарі перевіряються на образи й спам, підозрілі потрапляють на розгляд.

**Доступ і безпека**
- Реєстрація з паролем або вхід через Google; сесія в httpOnly cookie, вихід блокує токен.
- Модератор видаляє коментарі й оцінки; адміністратор керує світлинами будь-кого, банить користувачів і призначає модераторів.

**Інтерфейс**
- Адаптивна верстка від 320 px до десктопа, світла і темна тема, анімації з повагою до «зменшити рух».
- Lighthouse: 96-100 за всіма показниками на всіх сторінках.

## Стек

**Backend:** Node.js 22, Express 5, PostgreSQL 17, Prisma, zod, JWT, Cloudinary, Anthropic SDK, Swagger, Jest.
**Frontend:** Vite, vanilla JavaScript, HTML/CSS, Vitest.
**Інфраструктура:** Docker Compose, nginx, GitHub Actions.

Чому саме так - у [docs/TECH.md](docs/TECH.md).

## Швидкий старт

Потрібні Node.js 22+ і Docker.

```bash
cp .env.example .env          # заповнити значення, приклад у docs/DEVELOPMENT.md
docker compose up --build     # сайт на http://localhost:8080
```

Лише фронтенд з тестовими даними, без бекенду:

```bash
cd frontend && npm ci && npm run dev:mock
```

Розробка, змінні середовища і тести - у [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).
